# 🛠️ Tecnologias Utilizadas

## Backend

| Tecnologia | Versão | Propósito |
|-----------|--------|----------|
| **Quarkus** | Latest | Framework Java supersônico |
| **Java** | 25 | Linguagem de programação |
| **Hibernate ORM + Panache** | Latest | Persistência de dados e ORM |
| **PostgreSQL** | 12+ | Banco de dados relacional |
| **Maven** | 3.8+ | Gerenciador de dependências e build |
| **JUnit 5** | Latest | Framework de testes unitários |
| **SmallRye OpenAPI** | Latest | Documentação automática com Swagger UI |
| **RESTEasy Classic Jackson** | Latest | Framework REST com serialização JSON |
| **Agroal** | Latest | Connection pool para banco de dados |

## Ferramentas de Desenvolvimento

| Ferramenta | Propósito |
|-----------|----------|
| **IntelliJ IDEA Community** | IDE de desenvolvimento |
| **Git** | Controle de versão |
| **GitHub** | Repositório remoto |
| **Docker** | Containerização (futuro) |
| **Linux** | Sistema operacional da VPS |

## Dependências do Projeto

As dependências estão definidas no `pom.xml` e incluem:

- `quarkus-resteasy-jackson` — REST com JSON
- `quarkus-hibernate-orm-panache` — ORM com Panache
- `quarkus-jdbc-postgresql` — Driver PostgreSQL
- `quarkus-smallrye-openapi` — Swagger UI
- `quarkus-junit5` — Testes com JUnit 5
- `quarkus-agroal` — Connection pool
